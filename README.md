# Shittu Ajibade — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript. No build step or dependencies required.

## Run locally
Open `index.html` in your browser, or use VS Code Live Server.

## Deploy to Vercel
1. Create a new GitHub repository (for example `shittu-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In Vercel, choose **Add New → Project** and import the GitHub repository.
4. Use the following settings:
   - Framework Preset: **Other**
   - Build Command: leave empty
   - Output Directory: `.` (or leave the default if Vercel detects it)
   - Install Command: leave empty
5. Click **Deploy**.

You can also drag the project folder into a Vercel deployment flow if that option is available in your dashboard.

## Before publishing
- Confirm the contact email and social links.
- Check every project description and keep only work you can accurately represent.
- Replace the CSS-built project covers with approved screenshots if you want to show real project imagery.
- Add a CV PDF link if you'd like recruiters to download your CV.
- Add your own profile photo if you want a more personal introduction.

## Files
- `index.html` — page structure and content
- `style.css` — design, responsive layout and animations
- `script.js` — mobile navigation, current year and copy-email button
